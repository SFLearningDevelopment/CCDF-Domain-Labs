CCDV-F Claude Certified Developer – Foundations · Hands-on lab track

Prep Labs

Five labs following the five modules of the official course. Every stage carries working code in Python and TypeScript, so an exam answer becomes something you have run rather than something you have read.

The project

You build one thing across all five labs: policy-assistant, an internal tool that answers staff questions from your company's HR policy documents. Every stage changes the same project, and you are shown exactly what changed. Pick Python or TypeScript once and the whole track follows it.
