The project

You build one thing across all five labs: policy-assistant, an internal tool that answers staff questions from your company's HR policy documents. Every stage changes the same project, and you are shown exactly what changed. Pick Python or TypeScript once and the whole track follows it.

Words used in this lab

Accelerator
Something you build once and reuse, so the next project starts further along than the last one did.
Versioned prompt
A prompt kept in the repository like code, reviewed when it changes, with a record of which version each deployment ran.
Compaction
Summarising older turns into a short running note and keeping only recent ones word for word, so cost and quality stop degrading as a conversation grows.
Runbook
A short document telling somebody else how to run, check and repair what you built, without asking you.
Model pinning
Naming an exact model version in configuration so an upgrade is a decision you make and can undo, rather than something that happens to you.

2Turn your prompts into versioned artifacts

Stop the prompt being something that lives in one person's editor.

  1. Move every prompt into a prompts/ directory, one file per version.
  2. Load by version from configuration, so staging and production can differ deliberately.
  3. Record the version in every trace, so any answer traces back to the exact text that produced it.
  4. Change a prompt, bump the version, and confirm you can tell which answers came from which.

4Stop long conversations getting worse

Keep cost, speed and answer quality steady as a session grows, and know what compaction costs you.

  1. Add compact.py / compact.ts. Older turns become a short running note; the most recent stay word for word.
  2. Add long_session.py / longSession.ts and run it with COMPACT=0, then COMPACT=1. It prints tokens per turn and the summariser's own cost.
  3. Compare the two runs on four things: input tokens at turn 39, latency, total spend including the summariser, and whether the eval suite still passes.
  4. Run the memory check. Two facts are planted early: one the summary prompt is told to keep, and one it is not. Find the one that was lost.
  5. Tune the summary prompt until the lost fact survives, then re-run. This is the real work of compaction — the knobs are easy, the prompt is not.
