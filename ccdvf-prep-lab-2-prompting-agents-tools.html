The project

You build one thing across all five labs: policy-assistant, an internal tool that answers staff questions from your company's HR policy documents. Every stage changes the same project, and you are shown exactly what changed. Pick Python or TypeScript once and the whole track follows it.

Words used in this lab

Few-shot example
A worked example inside the prompt showing the answer you want. Most useful where the decision is hardest, not where it is already easy.
Prefill
Putting the first characters of the answer into an assistant entry at the end of the messages list. Claude continues from there, so a preamble has nowhere to go.
Tool schema
The description and parameter list you give Claude for a function it can ask you to run. It is the contract between your code and the model.
tool_use and tool_result
Claude asks for a function with a tool_use block carrying an id. You run it and send the answer back in a tool_result block carrying that same id.
Agent loop
Gather what you need, act, check the result, repeat until done or a limit stops you. The checking step is what makes it an agent rather than a script.
